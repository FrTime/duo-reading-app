# Duo Reader

A 3D bookshelf and reader for your own ebooks, built for iPhone Duo.

Import EPUBs, PDFs and other DRM-free files (AO3 downloads included), give each
one a 3D cover built from images found online or the file's own artwork, and
arrange them on a shelf. Read in any Duo pose with every setting you'd expect
from Kindle, and tag passages to build a searchable library of moments you
want to come back to.

Native iOS, SwiftUI. Headed for the App Store.
